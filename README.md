
# 🚴 Bike Sales Analysis Dashboard

### Microsoft Excel | Data Cleaning | Data Analysis | Data Visualization

An interactive **Bike Sales Analysis Dashboard** developed using Microsoft Excel to explore customer demographics, purchasing behavior, and factors influencing bike purchases.

This project analyzes customer data to identify patterns and generate meaningful business insights that can support data-driven decision-making.

---

## 📊 Project Overview

The Bike Sales Dashboard provides a visual overview of customer purchasing behavior based on demographic and lifestyle characteristics.

The dataset contains **1,026 customer records** with information about income, age, gender, occupation, education, commute distance, and bike purchasing decisions.

The dashboard transforms raw customer data into meaningful visual insights using Excel Pivot Tables and Pivot Charts.

---

## 🎯 Project Objectives

- Analyze customer bike purchasing behavior.
- Explore the relationship between income and bike purchases.
- Understand purchasing patterns across different age groups.
- Analyze customer commute distances.
- Identify demographic factors associated with bike purchases.
- Present findings through an interactive Excel dashboard.

## 📁 Dataset Description

The dataset includes the following attributes:

| Column | Description |
|---|---|
| ID | Unique Customer ID |
| Marital Status | Customer's marital status |
| Gender | Customer's gender |
| Income | Annual customer income |
| Children | Number of children |
| Education | Education level |
| Occupation | Customer's occupation |
| Home Owner | Home ownership status |
| Cars | Number of cars owned |
| Commute Distance | Customer's commute distance |
| Region | Customer's geographical region |
| Age | Customer's age |
| Purchased Bike | Whether the customer purchased a bike |

---

## 📈 Dashboard Insights

The dashboard includes the following visualizations:

### 1. Average Income Per Purchase
Compares average customer income based on bike purchasing decisions.

### 2. Customer Commute Analysis
Explores customer commute distances in relation to bike purchasing behavior.

### 3. Customer Age Brackets
Analyzes customer age groups to understand bike purchasing patterns.
